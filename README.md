# Folder Structure

### /web
React frontend built with Vite and TypeScript. Handles the user interface and client-side logic.

### /services
AWS Lambda handlers built with FastAPI and Python. Contains the core backend business logic.

### /infra
Infrastructure as Code (IaC) managed via Terraform. Handles cloud provisioning and deployment configurations.

### /scripts
Utility scripts for database seeding, automated testing, and development helpers.
